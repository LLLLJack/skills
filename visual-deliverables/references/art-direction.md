# Art Direction Selector

设计质量来自一致且具体的方向，而不是一串“高级、现代、简洁”的形容词。本文件提供可移植的方向库；先选一个主方向，再围绕用户品牌调整。

## 选择方法

从任务中提取四组词：

1. **领域**：金融、消费、文化、科技、教育、医疗、艺术……
2. **受众**：管理层、投资人、消费者、开发者、学生……
3. **情绪**：可信、克制、锐利、温暖、活力、实验……
4. **密度**：画廊式、常规、信息密集。

选择最吻合的一个方向。最多再借用另一个方向的一项技法，不要拼贴多个风格。用户给了品牌或参考图时，从参考中提取同样的角色变量，并以参考为准。

## A1 Editorial Ledger｜编辑部账本

- **适合**：研究报告、策略分析、年度回顾、严肃数据故事。
- **气质**：理性、可信、编辑感。
- **颜色**：纸白或暖灰底，墨色正文，酒红/深蓝/森林绿任选一个强调。
- **字体**：有性格的标题衬线 + 中性正文无衬线；数字可用等宽。
- **构图**：强左边线、跨栏标题、脚注与来源形成细节层，图表像杂志信息图而非 SaaS 卡片。
- **记忆点**：一条贯穿全文的编号、刻度或批注系统。
- **避免**：圆角卡片海、霓虹、无来源的大数字。

## A2 Precision Industrial｜精密工业

- **适合**：技术产品、机器人、制造、基础设施、B2B 系统。
- **气质**：精确、冷静、耐用。
- **颜色**：钛灰、炭黑、冷白，配安全橙或信号黄。
- **字体**：窄体或几何无衬线 + 等宽数字。
- **构图**：模块化网格、细线框、坐标和规格标注；高密度但保持严格对齐。
- **记忆点**：工程图式的测量线、索引号或剖面标记。
- **避免**：柔软大圆角、朦胧玻璃、无意义渐变。

## A3 Quiet Luxury｜静奢留白

- **适合**：高端消费、品牌故事、精品服务、艺术与餐饮。
- **气质**：克制、触感、从容。
- **颜色**：骨白、炭灰、深棕，配氧化金属或暗红点睛。
- **字体**：精致衬线标题 + 极简无衬线正文。
- **构图**：大面积负空间、少量大图、窄文本列、细分隔线。
- **记忆点**：一个精心裁切的主体或印章式小元素。
- **避免**：密集功能卡、过多徽章、廉价金色渐变。

## A4 Humanist Warmth｜人文温度

- **适合**：教育、健康、社区、公益、个人服务。
- **气质**：可信、亲近、乐观。
- **颜色**：暖白、黏土、鼠尾草、深棕或柔和蓝。
- **字体**：人文无衬线，必要时配温和衬线标题。
- **构图**：自然节奏、不完全对称、圆润但不过度的形状，真实人物与场景优先。
- **记忆点**：手绘注释、柔和剪影或故事性照片序列。
- **避免**：企业图库式握手照、儿童化插图、低对比粉彩文字。

## A5 Signal Brutalism｜信号粗野主义

- **适合**：音乐、潮流、青年文化、活动、实验品牌。
- **气质**：直接、反常规、有冲击。
- **颜色**：高对比黑白底，加一个高纯度信号色。
- **字体**：粗黑无衬线或等宽；字号差异极大。
- **构图**：硬边块面、可见网格、粗线、偏移阴影、局部越界。
- **记忆点**：一个超大词、编号或贴纸状符号。
- **避免**：所有元素都倾斜、失去对齐依据、为了“酷”牺牲阅读。

## A6 Living Archive｜活档案

- **适合**：历史、文化、人物、展览、时间线、知识库。
- **气质**：考据、叙事、可探索。
- **颜色**：档案纸、墨色、褪色蓝/红/绿。
- **字体**：书籍式衬线正文 + 标签无衬线或打字机风格。
- **构图**：索引、时间戳、页码、边注、照片说明与材料叠放。
- **记忆点**：编号标签与跨页线索。
- **避免**：仿旧滤镜过重、装饰盖过史料、伪造来源。

## A7 Kinetic Type｜动态字体

- **适合**：发布会、宣言、封面、短页数演示、强观点海报。
- **气质**：自信、节奏强、舞台感。
- **颜色**：两种高对比基色 + 单一强调。
- **字体**：一套有宽度或字重变化的展示字体为主。
- **构图**：文字本身成为图形；大字号、裁切、基线变化和重复形成节奏。
- **记忆点**：贯穿全稿的一个关键词或字形动作。
- **避免**：长段正文、每页不同字体、文字效果堆叠。

## A8 Material Dark｜材质暗场

- **适合**：AI、影音、游戏、硬件、夜间数据界面。
- **气质**：沉浸、精密、电影感。
- **颜色**：带色相的近黑、深灰表面、低饱和冷色或暖色强调。
- **字体**：清晰无衬线 + 等宽数字。
- **构图**：光线来自内容而非外发光；层级依靠亮度、细边和局部材质。
- **记忆点**：一束受控的光、反射或微弱网格。
- **避免**：紫蓝渐变铺满、所有卡片发光、低对比灰字。

## A9 Data Editorial｜数据编辑设计

- **适合**：仪表盘、运营复盘、市场研究、财务分析。
- **气质**：清晰、洞察先行、专业。
- **颜色**：中性底色 + 语义色；强调色只标记结论。
- **字体**：中性无衬线 + 表格数字等宽。
- **构图**：结论标题、注释式图表、直接标注、对齐的数字列，少用容器。
- **记忆点**：每张图只突出一个关键变化，并用一句话解释“所以什么”。
- **避免**：彩虹图例、3D 图表、装饰性仪表盘、把所有指标都做成卡片。

## A10 Playful Modular｜趣味模块

- **适合**：消费应用、亲子、创作者工具、轻量活动与社区。
- **气质**：活泼、友好、有组织。
- **颜色**：柔和底色 + 2 个协调亮色；确保正文对比度。
- **字体**：圆润或几何无衬线，标题可用更具个性的字形。
- **构图**：不同尺寸的模块、插画或物件形成节奏，重复同一形状语言。
- **记忆点**：一个角色、图形或可重复的玩具式组件。
- **避免**：每块不同颜色、气泡堆满页面、把专业内容幼儿化。

## 落地为变量

选定方向后，把描述转成具体值：

```text
background: #...
surface: #...
text: #...
muted: #...
accent: #...
display type: ...
body type: ...
grid: ... columns / ... gutter
radius: ...
line: ...
shadow or texture: ...
signature move: ...
```

先确认这些变量互相协调，再开始画局部组件。字体不可用时选择同类气质的系统回退字体，不要为了名字强行远程加载。
