# Poster, Cover & Banner Guidelines

海报不是缩小的网页，也不是只有一页的幻灯片。它要在极短时间内传达一个主信息，并在近看时提供必要细节。

## 1. 先定信息层级

把内容压缩成最多五组：

1. Hero：主体图像或主标题二选一
2. Main message：核心标题
3. Support：一句副标题或价值说明
4. Meta：日期、地点、价格、人物等
5. Action / brand：CTA、二维码、Logo、网址

同一级不要出现多个竞争元素。内容过多时删减、分系列或制作详情页，不要把所有字缩小塞进一张图。

## 2. 选择一个构图骨架

### P1 Type Field

主标题本身是画面，占宽度 60–90%；其他信息沿同一边线排列。适合宣言、活动、音乐、编辑封面。

### P2 Subject + Quiet Zone

一个人物、产品或物件占主要视觉质量，标题落在明确的安静区域。适合发布、展览、电影和产品。

### P3 Hard Split

画布切成 35/65、40/60 或对角的两块，一边承担信息，一边承担视觉。适合 Banner、讲座、促销和科技主题。

### P4 Modular Editorial

使用 4–6 列网格组织较多节目、议程或清单；大标题和色块建立层级。适合节日、会议和信息密集型活动。

### P5 Diagonal Energy

只使用一条斜向主轴，让标题、色带或主体沿它运动；元信息回到水平基线以保证阅读。适合体育、青年、促销。

### P6 Quiet Mark

大量负空间，保留一个精心放置的标题、印记或主体。适合高端品牌、艺术、书籍和生活方式。

不要先画完再选骨架。骨架决定图像裁切、字号和信息容量。

## 3. 建立三角色色板

- **Dominant**：背景或最大色块，约占主要视觉质量。
- **Secondary**：主体、标题或结构色。
- **Accent**：只用于日期、CTA、关键词或一个识别符号。

通常 3 个角色已经足够；中性色的明暗变化不算新增品牌色。确保正文和元信息对背景有足够对比。

## 4. 字体与尺度

- 最多 2 套字体，一套展示、一套支持；一套字体用多字重往往更强。
- 标准 1080px 短边画布可从以下范围起步：Hero 标题 120–220px，标题 80–140px，副标题 44–72px，正文 28–44px，Meta 24–36px。
- 小画布不是按比例缩小全部文字的理由；先删内容和增加换行。
- 主体与第二层信息的尺度差要明显，避免所有字只差一个字号档。
- 重要文字必须是活字或矢量，不能烘焙进生成图片。

## 5. 图像策略

- 一张海报通常只有一个主视觉。多张照片必须通过统一裁切、双色调、颗粒或色彩覆盖形成同一系统。
- 主视觉应留出标题可以落位的 quiet zone；没有则重新裁切或增加受控遮罩。
- 生成图像时描述主体、镜头、光线、材质、情绪、色板和留白位置，不让模型生成文字。
- 优先寻找能同时表达两个概念的视觉隐喻，而不是字面插图。
- Logo、二维码和精确信息单独叠加，保持清晰。

## 6. 对齐与负空间

- 每个元素都对齐到网格、边线、中心轴或共同基线。
- 相关信息组内间距小，组间间距至少明显大一档。
- 画布四周保留安全区；数字发布稿通常至少为短边的 5%，社交方图建议 8%。
- 负空间要形成可感知的形状，不是随机空洞。

## 7. 输出前检查

- 10–15% 缩略图下是否仍能认出标题和唯一焦点？
- 视线是否自然按 Hero → 标题 → Meta → Action 移动？
- 是否有三个以上竞争焦点？有则删除或降级。
- 字体、颜色、线条、图形语言是否统一？
- 关键信息是否被裁切、盖住或埋在复杂图片上？
- Banner 多尺寸版本是否重新构图，而不是机械缩放？
